# External Resources

Tools, repositories, and reference material outside the pathway corpus. Cite one only when it is genuinely relevant to what the user raised — never pad a response with a resource just because it exists. Always label these as an external tool or reference, not a documented pathway: no contributor attribution, no condition tag, since none of this is sourced from a deployment write-up. State plainly what it is and why it's relevant, then let the user decide whether to look further.

## Voicera

Open-source voice AI and telephony platform, maintained by COSS-India, MIT licensed. Provides real-time speech-to-text, text-to-speech, and LLM-powered conversational agents, with AI4Bharat and Bhashini integration for Indian-language voice stacks. Relevant when a user is evaluating or building their own voice AI telephony infrastructure, especially for Indic-language deployments — the same kind of build the Bhili pathway's own team drew on ("Voicera — Voice stack learnings" in that deployment's own partner list).

- Repository: https://github.com/COSS-India/voicera_mono_repository
- Documentation: https://voicera.gitbook.io/voicera-docs
